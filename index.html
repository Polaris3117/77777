🎯 เมนูนี้ทำงานอย่างไร?

เมนูนี้ใช้สำหรับ ตั้งงบประมาณ ของแต่ละหมวด/แผนงาน ในปีงบประมาณ — ระบบจะตรวจยอดคงเหลืออัตโนมัติเมื่อมีการบันทึกรายจ่าย และเตือน/บล็อกเมื่อใช้งบเกิน

📝 ขั้นตอนการใช้งาน

  1. กด "+ เพิ่มรายการงบ" → กรอก: ชื่อแผนงาน / หมวด / ยอดที่ตั้งไว้
  2. ระบบจะแสดง ยอดใช้แล้ว / ยอดคงเหลือ / % การใช้ แบบเรียลไทม์
  3. เมื่อบันทึกในเมนู "📤 จ่ายเงิน" ระบบจะหักงบประมาณตามหมวดอัตโนมัติ

💡 เคล็ดลับ

  • ปีงบประมาณไทยคือ 1 ตุลาคม - 30 กันยายน — ระบบคำนวณให้อัตโนมัติ
  • ดูสีสถานะ: 🟢 ปกติ / 🟡 เตือน 80%+ / 🔴 เกิน 100%

🎯 เมนูนี้ทำงานอย่างไร?

เมนูนี้ใช้สำหรับ บันทึกรายรับเงินทั้งหมด ของโรงเรียน — ทั้งเงินอุดหนุนจาก สพฐ., อปท., ค่าธรรมเนียม, ดอกเบี้ย, เงินบริจาค ฯลฯ และออกใบเสร็จรับเงิน

📑 3 Tab ใช้ทำอะไร?

  • รายการรับเงิน → ดูทุกรายการรับเงิน + กดปุ่ม 🖨️ ใบเสร็จ ในแถวเพื่อพิมพ์
  • ออกใบเสร็จรับเงิน → เลือกรายการที่จะออกใบเสร็จ + ดู Preview + พิมพ์/ส่งออก Word
  • สรุปรายรับ → สรุปยอดแยกตามหมวด

📝 ขั้นตอนรับเงิน + ออกใบเสร็จ

  1. กด "+ บันทึกรับเงิน" → กรอก: วันที่ / ผู้ชำระ / รายการ / หมวด / จำนวนเงิน
  2. เลือกสถานะ "รับแล้ว" → กด "💾 บันทึก"
  3. ในตาราง กดปุ่ม "🖨️ ใบเสร็จ" สีเขียว → พิมพ์ใบเสร็จได้ทันที

💡 เคล็ดลับ

  • ระบบเก็บรายชื่อ "ผู้ชำระ" และ "รายการ" ไว้ — พิมพ์ครั้งถัดไประบบจะแนะนำให้
  • ใบเสร็จไม่มีตราครุฑ (ตามมาตรฐานเอกสารบัญชี)
  • เลขใบเสร็จออกอัตโนมัติ — แก้ไขได้ในช่อง "เลขที่ใบเสร็จ"

🎯 เมนูนี้ทำงานอย่างไร?

เมนูนี้ใช้สำหรับ บันทึกรายการจ่ายเงิน ทุกประเภท พร้อมออกใบสำคัญจ่ายและแบบขอเบิกเงินตามมาตรฐานเอกสารราชการ

📑 3 Tab ใช้ทำอะไร?

  • รายการจ่ายเงิน → ดูทุกรายการจ่าย + แก้ไข/ลบ + ดูสถานะ
  • ใบสำคัญจ่าย → ออกใบสำคัญจ่าย (Payment Voucher) สำหรับการชำระแต่ละครั้ง
  • แบบขอเบิกเงิน → แบบฟอร์มขออนุมัติเบิกเงินจาก ผอ.

⚠️ ระบบเตือนเมื่อใช้งบเกิน

🤖 AI ควบคุมงบประมาณอัตโนมัติ:
🟢 ใช้งบ < 80% → บันทึกได้ปกติ
🟡 ใช้งบ 80-99% → เตือนก่อนบันทึก
🔴 ใช้งบ ≥ 100% → บล็อกการบันทึก ป้องกันใช้เกิน!

📝 ขั้นตอนการบันทึก

  1. กด "+ บันทึกจ่ายเงิน" → กรอกข้อมูล: วันที่ / ผู้รับเงิน / รายการ / หมวดงบ / จำนวนเงิน
  2. เลือกหมวด "งบประมาณ" ที่จะหักออก (ระบบจะตรวจยอดคงเหลือ)
  3. กด "💾 บันทึก" → ระบบจะหักงบประมาณอัตโนมัติ
  4. ไปที่ Tab "ใบสำคัญจ่าย" → เลือกรายการ → พิมพ์

💡 เคล็ดลับ

  • ใบสำคัญจ่าย/แบบขอเบิกไม่มีตราครุฑ (ตามมาตรฐานเอกสารบัญชี)
  • หากต้องส่งหนังสือเบิกเงินไปหน่วยงานอื่น ใช้เมนู "📝 แบบฟอร์มราชการ" → "หนังสือราชการภายนอก"

📚 ทะเบียนนักเรียน?
เก็บอัตโนมัติ เมื่อบันทึกครั้งแรก — ครั้งถัดไป พิมพ์ชื่อ ระบบจะแนะนำ + เติมข้อมูลให้
🖨️ พิมพ์ใบเสร็จ?
กดปุ่ม "🖨️ ใบเสร็จ" สีเขียวในตาราง สำหรับรายการที่ ชำระแล้ว
💡 ขั้นตอน 4 ข้อ: ➊ เพิ่มรายการ → ➋ พิมพ์ชื่อนักเรียน (autofill ทำงาน) → ➌ เลือกห้อง+ภาคเรียน → ➍ บันทึก พิมพ์ใบเสร็จได้ทันที

🎯 เมนูนี้ทำงานอย่างไร?

เมนูนี้ใช้สำหรับ บันทึกข้อมูลบุคลากร + คำนวณบัญชีเงินเดือนประจำเดือน + ออกเอกสารเงินเดือนเพื่อนำส่งธนาคาร

📑 3 Tab ใช้ทำอะไร?

  • ข้อมูลบุคลากร → เพิ่ม/แก้ไขรายชื่อครูและเจ้าหน้าที่ พร้อมเงินเดือน
  • บัญชีเงินเดือนประจำเดือน → สรุปรวมเงินเดือนประจำเดือน คำนวณรับสุทธิ
  • เอกสารเงินเดือน → พิมพ์บัญชีถือจ่าย + หนังสือนำส่งเงินเดือนไปธนาคาร (มีตราครุฑ)

📝 ขั้นตอนการใช้งาน

  1. เพิ่มบุคลากรทั้งหมดใน Tab "ข้อมูลบุคลากร"
  2. ทุกเดือน → เลือก Tab "บัญชีเงินเดือนประจำเดือน" → เลือกเดือน
  3. ระบบจะคำนวณ เงินเดือน + ค่าครองชีพ - หัก = รับสุทธิ ให้อัตโนมัติ
  4. ไปที่ "เอกสารเงินเดือน" → พิมพ์/ส่งออก Word ส่งธนาคาร

💡 เคล็ดลับ

  • ระบบรองรับ วิทยฐานะ ครู (ครูผู้ช่วย/ค.ศ.1-4)
  • หนังสือนำส่งธนาคารมีตราครุฑ (เป็นหนังสือราชการภายนอก)
  • บัญชีถือจ่ายไม่มีตราครุฑ (เป็นเอกสารบัญชีภายใน)

📋 สิ่งที่ตั้งได้

  • 🏫 ข้อมูลโรงเรียน → ชื่อ/ที่อยู่/สังกัด/โทร — ใช้ใน header เอกสารทุกชนิด

  • 🖼️ อัปโหลดตราโรงเรียน + ตราครุฑ → แสดงใน header เอกสาร
  • ✍️ อัปโหลดลายเซ็น → ระบบใส่ลายเซ็นเหนือเส้นลงชื่ออัตโนมัติ
  • 🔐 เปลี่ยนรหัสผ่าน + กู้คืนด้วย Master Recovery Key
  • 💾 Backup/Restore → ส่งออก/นำเข้าข้อมูลทั้งหมด
  • 🗑️ เคลียร์ข้อมูล → ลบข้อมูลทั้งหมด เริ่มต้นใหม่

⚠️ คำเตือน: ตั้งค่าให้ครบก่อนใช้งานจริง — โดยเฉพาะ ข้อมูลโรงเรียน และ ชื่อ ผอ. เพราะระบบใช้กรอกในเอกสารทุกฉบับ

💡 ระบบพื้นที่จัดเก็บข้อมูลของ LocalStorage
ระบบใช้พื้นที่จัดเก็บข้อมูลในเบราว์เซอร์ของผู้ใช้ (LocalStorage) ซึ่งเบราว์เซอร์แต่ละยี่ห้อมีขีดจำกัดแตกต่างกัน (Chrome/Edge: ~10 MB | Firefox: ~10 MB | Safari: ~5 MB) เมื่อพื้นที่ใกล้เต็มระบบจะแจ้งเตือนอัตโนมัติ
🎯 วิธีเพิ่มพื้นที่จัดเก็บข้อมูล
🗂️ 1. เก็บข้อมูลเก่าเข้าคลัง (Archive)
ส่งออกและลบข้อมูลปีงบประมาณเก่าที่ไม่จำเป็นต้องใช้ประจำ
🗜️ 2. บีบอัดข้อมูล (Compress)
ลบฟิลด์ที่ว่างเปล่าและข้อมูลที่ซ้ำซ้อนเพื่อประหยัดพื้นที่
🖼️ 3. ปรับปรุงขนาดภาพตรา (Optimize Images)
ลดขนาดตราครุฑ/ตราโรงเรียนให้เล็กลงเพื่อประหยัดพื้นที่
💾 4. สำรอง + ล้างรายการที่ยกเลิก
ดาวน์โหลดไฟล์สำรองก่อน แล้วลบรายการสถานะ "ยกเลิก" ออกทั้งหมด
